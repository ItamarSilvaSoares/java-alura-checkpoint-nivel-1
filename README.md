# Projeto: Reserva de salas
Agora que você já percorreu os primeiros cursos da carreira, chegou a hora de aplicar o que aprendeu em um projeto prático!

Neste desafio, você irá construir uma API para gerenciamento de reservas de salas utilizando tudo que você aprendeu até agora. Cada funcionalidade do projeto será apresentada de forma detalhada em etapas que vão te guiar para alcançar o objetivo final de construir uma aplicação Java com Spring focada em APIs CRUD, persistência com Spring Data JPA e testes de unidade. Você praticará orientação a objetos, camadas (controller/service/repository), regras básicas de negócio (conflitos de horários), qualidade de código e versionamento com Git/GitHub.
